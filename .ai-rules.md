# AI Rules for Smart Email Manager

This file provides guidelines for AI agents (like Gemini CLI) when working on this repository.

## Project Context
- **Name:** Smart Email Manager
- **Core Stack:** Python (3.11+), FastAPI, MongoDB Atlas (Vector Search), Google Gmail API, MCP (Model Context Protocol).
- **Purpose:** Semantic email organization and automation.

## Coding Standards
- **Type Hints:** Use type hints for all function signatures.
- **Async:** Use `async/await` for FastAPI endpoints and I/O bound operations where supported.
- **Naming:** Follow PEP 8 (snake_case for variables/functions, PascalCase for classes).
- **Documentation:** Use Google-style docstrings for functions and classes.
- **Error Handling:** Use specific exception types and provide meaningful error messages.

## Architectural Patterns
- **Tools:** Keep tools in the `tools/` directory. Use FastMCP for defining agent tools.
- **Database:** All MongoDB interactions should go through `db/mongo_client.py` or dedicated operation files in `tools/`.
- **Configuration:** Use `config/settings.py` for managing environment variables and app settings.

## MongoDB Vector Search
- **Embedding Model:** Default is `voyage-3` via Voyage AI.
- **Vector Index:** The vector index in MongoDB is named `vector_index`.
- **Dimensions:** Ensure embeddings match the dimensions expected by the index (typically 1024 or 2048 depending on the model).

## Gmail API & MCP
- **OAuth:** Respect the OAuth flow. Do not hardcode credentials.
- **FastMCP:** When adding new Gmail capabilities, wrap them in `@mcp.tool()` decorators in `tools/gmail_mcp.py`.
- **Scopes:** Only request the minimum necessary Gmail scopes.

## Deployment
- **Cloud Run:** Maintain `deploy/Dockerfile` and deployment scripts. Ensure `PORT` environment variable is respected (default 8080).

## Testing
- Add tests for new features in files prefixed with `test_`.
- Use `pytest` for running tests.
